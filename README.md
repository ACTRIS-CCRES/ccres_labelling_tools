# Cloudnet Data Coverage
Script to get daily data coverage info associated to Cloudnet's products
for different National Facilities on a monthly time basis

--- 
## Usage
- ```python run_get_data_coverage.py``` (default)
- ```python run_get_data_coverage.py --date 20260501 20260531``` (specific period for all sites defined in conf.py)
- ```python run_get_data_coverage.py --site bucharest --site palaiseau --site munich --date 20260501 20260531 --makeplot True```
